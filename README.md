# 新月 · 生日快乐（Vue3 平板互动生日程序）

一份可以"拿到手直接运行"的平板端生日互动网页：星空新月主题，进入后播放《生日快乐歌》，依次闯过小关卡，收集密码开箱领取生日礼物；附 3 个小游戏 + 幸运大转盘抽奖。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（默认 http://localhost:5173/）
npm run build   # 生产构建（产物在 dist/）
```

> 推荐在平板或桌面浏览器以**横屏全屏**打开，体验最佳。纯前端项目，无需后端。

## 玩法流程

1. **开屏**：点击屏幕解锁并播放《生日快乐歌》背景音乐
2. **欢迎页**：点击「领取你的生日礼物」
3. **惊喜游乐园**：完成 3 个小游戏（接星星 / 翻牌配对 / 点泡泡），每完成 1 个获得 1 次**大转盘抽奖**机会
4. **主线三关**：吹蜡烛 → 回忆小测验 → 刮刮卡，每关收集一个数字
5. **开箱密码**：输入三关收集的数字（默认 520）解锁礼盒
6. **礼物揭晓**：彩纸爆发，口红与项链登场 + 祝福语

## 自定义配置

所有内容集中在 `src/config.js`：

| 配置项 | 说明 |
|---|---|
| `name` / `dateText` | 对方昵称 / 生日日期显示 |
| `quiz` | 三关小测验题目与答案（`correct` 为正确选项下标） |
| `codeParts` | 三关收集的数字，组合成开箱密码（默认 `['5','2','0']`） |
| `prizes` | 大转盘 12 个奖品（名称、情话 tag），图片从 `src/assets/prizes-grid.jpg` 网格自动裁剪 |
| `gift` / `message` | 礼物文案与最终祝福语 |
| `musicUrl` | 背景音乐地址，留空时尝试读取 `public/music/happy-birthday.mp3` |

## 背景音乐

- 放入 `public/music/happy-birthday.mp3` 即播放真实音频
- 没有音频文件时，程序自动用 Web Audio 合成《生日快乐歌》旋律循环播放（无需任何素材）
- 浏览器要求用户先交互（点击开屏）才能出声，属正常行为

## 技术栈

Vue 3 + Vite + JavaScript，Canvas 实现星空/彩纸粒子、转盘与刮刮卡，CSS 变量主题（深空紫 × 金 × 粉），布局使用 `vmin / clamp` 响应式适配平板大屏。
